# 安装与升级

## 运行环境

- macOS
- Node.js 22.0.0 或更高版本
- 能读取当前锁文件的 pnpm，Yanxu 不限制 pnpm 主版本
- Git
- OpenCode CLI 或 Claude Code CLI；仅在创建人员、设置协调器和启动实际任务时校验对应 CLI

## 首次安装

```bash
git clone <repository-url>
cd Yanxu
./yanxu
```

`./yanxu` 会安装锁定依赖、检查 `better-sqlite3` 与当前 Node.js ABI、构建前后端，停止已验证的旧 Daemon 后启动新版本。默认访问 `http://127.0.0.1:43120`。

## 升级

1. 确保当前任务已暂停或交付，保留代码任务分支。
2. 更新 Yanxu 源码。
3. 运行 `./yanxu`。
4. 在“设置 → 系统与存储”核对应用版本、Schema 版本、SQLite `quick_check` 和升级恢复点。
5. 重新检测 CLI，对任务将使用的 OpenCode/Claude Code 执行真实 Runtime 自检。

已有数据库需要新迁移时，Yanxu 会先执行 WAL checkpoint 和 SQLite `VACUUM INTO`，通过 `quick_check` 后才应用迁移。首次创建空数据库不会制造无意义恢复点。

## 启动命令

```bash
./yanxu                 # 构建并启动
./yanxu dev             # 开发模式
./yanxu db-backups      # 列出数据库迁移恢复点
./yanxu restore-db <file> # 恢复指定迁移恢复点
```

`YANXU_HOME` 可临时改变数据目录，`YANXU_PORT` 可改变端口。恢复命令只接受当前 `YANXU_HOME/system/migration-backups` 中由 Yanxu 创建的文件。
