# Yanxu 1.5 UI 视觉回归基线

本清单用于人工验收和保存实际截图。参考图位于 [`assets/multica-ui-reference`](./assets/multica-ui-reference/)，只比较信息层级、密度和可观察性，不逐像素复制。

## 截图规格

- 桌面宽屏：1440 × 1000。
- 紧凑桌面：1100 × 800。
- 每个页面分别保留正常、空状态以及存在阻塞/失败时的截图；没有对应数据时不伪造状态。
- 截图放入 `docs/assets/yanxu-ui-baseline/1.5.0/`，文件名使用下表建议名称。

## 页面基线

| 页面 | 建议文件名 | 必须看清的内容 |
| --- | --- | --- |
| 全局调度台 | `01-dashboard.png` | 并行任务条、已完成/当前/后续阶段、待处理、系统状态 |
| 项目详情 | `02-project.png` | 任务、知识、关联资源、能力、ProjectSpace 历史相互独立 |
| 任务计划 | `03-task-plan.png` | 需求版本、推荐方案、歧义回答、步骤、人员、能力、目录与分支 |
| 任务执行 | `04-task-execution.png` | 固定上下文条、当前阶段、真实变更、门禁、评审与证据入口 |
| Run 详情 | `05-run-viewer.png` | 事件筛选、相对时间、工具/错误、Session、重试关系和日志 |
| 交付报告 | `06-delivery.png` | Markdown 层级、变更、测试评审、冲突和交付动作 |
| 能力中心 | `07-capabilities.png` | 来源、类型、CLI 兼容、安装/启用/装载和健康状态 |
| AI 团队 | `08-team.png` | Role、人员、CLI/模型、能力偏好和团队成员池 |
| 运行环境 | `09-settings.png` | OpenCode/Claude 状态、能力矩阵、协调模型与系统诊断 |
| 定时任务 | `10-schedules.png` | 来源边界、执行模式、下次运行、重叠策略和历史任务 |

## 人工检查

- [ ] 1440px 与 1100px 下没有横向遮挡主要操作。
- [ ] 侧栏收起后图标与选中状态仍可识别。
- [ ] 仅使用键盘可以到达创建、确认、暂停、停止、恢复、交付和 Run 筛选。
- [ ] 焦点环清晰，不被卡片或滚动容器裁切。
- [ ] 等待、阻塞、失败、停止、重试和完成都显示文字，不只靠颜色。
- [ ] Markdown 表格、代码块和超长路径不会撑破页面。
- [ ] Run 大量事件和日志可以局部滚动，不挤压右侧上下文。
- [ ] 模态框在 800px 高度下可滚动并可访问底部按钮。
- [ ] 页面刷新与懒加载资源更新后不出现白屏或旧 Hash 404。
